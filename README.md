# A Computer Vision-Based Fuzzy Control System for Traffic Signals

## Abstract
In densely populated areas such as university surroundings, it is challenging of accommodating large volumes of pedestrian crossings with conventional traffic signal control, this paper designs and implements a fuzzy traffic signal control system based on computer vision. The system uses YOLOv8 and OpenCV to detect pedestrians and vehicles at intersections in real time and dynamically adjusts pedestrian green-light extension time through Mamdani fuzzy inference method. A simulation model based on scenarios around Guangzhou University, University Town campus was established based on queueing theory. Experimental results shows that compared with the fixed-time signal control scheme, the proposed system can significantly improve pedestrian traffic efficiency, which reduced the average queue length by 76\% and shorten the average waiting time by 78\%, while showing better adaptability during traffic recovery periods. The results indicate that combining computer vision with fuzzy control for pedestrian-intensive intersections is feasible and has practical engineering value.

## Keywords
computer vision; traffic signal control; fuzzy control; intelligent transportation systems
